# Resume claim audit

Reviewed on 2026-08-13 for the Senior Data Engineer resume.

## Positioning decision

The resume targets Senior Data Engineer roles first. It also shows genuine backend
engineering and data-platform observability experience that can transfer to Senior
Software Engineer and MLOps-adjacent roles. It does not claim professional model
training, model deployment, or ML platform operations.

## Removed claims

The corrected resume deliberately excludes:

- the Retail Demand MLOps Demo
- MLflow, model registry, model serving, and model drift
- MLOps Engineer or Machine Learning Engineer titles
- agentic AI, Claude Code, Looper, Pasin, and agent orchestration
- AWS and MongoDB, which were not included in the latest operator confirmation
- JavaScript and C++, which were not needed for the target and were not reconfirmed
- invented scale, percentages, uptime, latency, revenue, team size, or business impact
- claims that anomaly detection involved production ML models

## Wording policy

- Employer-issued titles remain unchanged.
- The headline is a target position, not a claim that GROPYUS issued the title
  "Senior Data Engineer."
- Current-role bullets use present tense; previous roles use past tense.
- Keywords appear inside supported experience or skill context.
- No em dash or double-hyphen prose appears in the resume body.
- Outcomes use "supporting" when no measured result was supplied.
