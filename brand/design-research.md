# Original portfolio design specification

Audit date: 2026-08-22

## Ownership boundary

Current page design is a repository-native composition created for Saurabh Shubham. No portfolio, template, theme, design-system package, stock asset, remote font, or third-party visual component is incorporated. Accessibility, semantic HTML, structured metadata, and crawler protocols are public interoperability standards rather than visual source material.

## Visual identity

- Personal `SS` wordmark with orbit detail.
- Editorial production-systems narrative built from signal strips, numbered system nodes, operational cards, and a technical stack core.
- Warm paper, charcoal, signal-orange, violet, and blue palette with an independently defined dark theme.
- Large condensed-feeling system-font typography, compact monospace labels, bordered surfaces, and controlled depth.
- Responsive composition authored for wide desktop through compact mobile without external layout frameworks.

## Interaction identity

- Native anchor navigation and semantic sections keep core content available without JavaScript.
- Theme choice persists locally; copy-email feedback uses an accessible live region.
- Scroll reveals are enhancement only. Reduced-motion users receive static content.
- Keyboard focus, skip navigation, target sizing, and high base contrast are first-class constraints.

## Content identity

The page presents only evidence-reviewed personal history, verified technologies, and one independently labelled project. Employer and product names are factual identifiers, not borrowed brand styling. Public claims remain governed by `brand/evidence-matrix.md`.

## Runtime boundary

Production uses local HTML, CSS, JavaScript, SVG, and PNG files only. No runtime framework, component library, CDN, tracking service, web font, or external script controls the visual experience.
